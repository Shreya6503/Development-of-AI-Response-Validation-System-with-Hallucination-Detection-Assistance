Development of AI Response Validation System with Hallucination Detection Assistance

## Run the application

Install the dependencies and start Streamlit from the project root:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The server listens on `0.0.0.0:8501`, which allows Codespaces and other
development environments to expose it through their port-forwarding service.

To open it in GitHub Codespaces:

1. Start the app with the command above.
2. Open the **Ports** panel.
3. Make port `8501` public or select the **Open in Browser** action.
